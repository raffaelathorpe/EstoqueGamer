# 🎮 EstoqueGamer

Sistema de controle de estoque para produtos gamers e tecnológicos desenvolvido como Progressive Web App (PWA) para a disciplina de Desenvolvimento Web.

## 📱 Funcionalidades

- ✅ **Gerenciamento de produtos** - Adicione, visualize e exclua produtos
- ✅ **Filtros** - Filtrar por Gamers, Tecnologia ou Todos
- ✅ **Busca** - Encontre produtos rapidamente
- ✅ **API de produtos** - Carregue produtos automaticamente da DummyJSON API
- ✅ **PWA** - Instalável como aplicativo no celular
- ✅ **Geolocalização** - Use o GPS do dispositivo para localizar o estoque
- ✅ **Funciona offline** - Service Worker para cache
- ✅ **Responsivo** - Funciona em qualquer dispositivo

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Progressive Web App (PWA)
- Service Worker
- Geolocation API
- DummyJSON API
